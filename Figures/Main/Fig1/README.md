# Main Fig. 1: physical model, collective scattering, and BA/SCBA diagrams

`Fig1.tex` is the editable TikZ body input directly by `main.tex`. Panel (c)
shows the bare internal propagator used in BA and the dressed internal
propagator used in SCBA. Rebuild the figure
as part of the main document from the project root:

```bash
latexmk -pdf main.tex
```

It has no numerical cache and does not launch a calculation.
