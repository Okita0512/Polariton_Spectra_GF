# Fig. S7 — finite-temperature Drude--Lorentz dimer benchmark

This folder generates the paper's ancillary realistic-bath dimer benchmark:
a 3 x 3 montage of the nine signed-`J` HEOM and site-local SCBA spectra.  The
figure contains panels (a)--(i) only.  It has no Wasserstein panel, panel (j),
peak-shift annotations, or parameter retuning.

## Physical scope

The fixed parameters are

```text
lambda = 30 meV per site
omega_f = 24.8 meV
T = 300 K
J = -100, -50, -25, -12.4, 0, 12.4, 25, 50, 100 meV
```

For the Drude--Lorentz spectral density, `omega_f` is an overdamped bath
correlation/cutoff scale, not the frequency of a coherent discrete vibronic
level.  Thus `2J = omega_f` is not an exact bright--dark avoided-crossing
condition analogous to `2J = nu_0` in the controlled single-mode calculation.
At 300 K, phonon emission and absorption both contribute, while the broad
continuum comparison combines the local closure error, thermal processes,
broadening, and exchange-dependent redistribution.  The remaining deviations
are therefore treated as modest, nonmonotonic line-shape differences rather
than a locator for a discrete vibronic resonance.  The calculation does not
isolate or prove an error-cancellation mechanism.

The command-18 `W1(J)` table and its validation are retained under `results/`
as explicitly **unplotted diagnostics**.  They are not generated by Fig. S7
driver, are not shown in `Figures/SI/FigS7/FigS7.pdf`, and are not used for a resonance
claim.  The physical parameters were not altered in response to that trend.

## Layout and provenance

- `plot_FigS7.py`: figure driver; produces exactly nine spectral axes.
- `data_manifest.csv`: small project-relative index of the active raw arrays.
- `results/area_normalization_validation.csv`: per-case raw-area,
  negative-tail, support, grid, and normalized-area checks.
- `results/area_normalization_validation.txt`: aggregate figure validation.
- `results/drude_dimer_W1_unplotted.csv`: archived, unplotted diagnostic.
- `results/drude_dimer_W1_unplotted_validation.txt`: archived diagnostic
  provenance and checks.
- `../Figures/common/dimer/drude/benchmark.py`: reusable loading and normalization
  utilities.
- `FigS7.pdf`: publication-ready vector PDF in this owner folder.

Revision 28 aligns the renderer with `Figures/common/si_plot_style.py`:
HEOM retains a light-blue fill/blue solid boundary and SCBA is the common red
dashed method curve, with shared typography, ticks, legend, and panel letters.
Panel letters and signed-`J` identifiers now share a reserved band above each
axes instead of covering the spectra. This is a plotting-only change.
The 5.65-inch native width is matched to a `0.80\linewidth` SI inclusion;
this avoids down-scaling the shared 8--10 pt source typography on the page.

No large numerical array is duplicated during this migration.  The complete
active HEOM case directories were moved to `Figures/common/dimer/drude/raw/heom/`, and
the nine SCBA spectra plus their summary and validation were moved to
`Figures/common/dimer/drude/raw/scba/`.  Drude generation and plotting history is
clearly separated under `Figures/common/dimer/drude/archive/`.  The unrelated
single-site outputs are retained canonically under
`Figures/SI/FigS2/results/`; the
redundant `test-2-sites/` directory was removed after all 50 files were
verified byte-for-byte.

The HEOM conversion is

```text
energy_eV         = resp1st.w1   * 27.211397
absorption_per_eV = resp1st_im.w / 27.211397
```

The active HEOM and SCBA grids coincide on the common physical support
`0.8000--3.1998 eV`; no interpolation is needed.  The tiny validated negative
HEOM Fourier-ringing tail is recorded and clipped to zero before unit-area
normalization.  Each nonnegative HEOM and SCBA spectrum is then normalized
separately with trapezoidal integration on that same support.  Only the
`1.80--2.30 eV` central window is displayed.

## Exact command

From the project root:

```bash
python3 Figures/SI/FigS7/plot_FigS7.py
```

This deterministically rewrites `Figures/SI/FigS7/FigS7.pdf` and both
`area_normalization_validation` files.

The final PDF can be rendered for inspection with

```bash
mutool draw -r 180 -o /tmp/FigS7.png Figures/SI/FigS7/FigS7.pdf 1
```
