# Fig. S8 — dimer diagrammatics

`FigS8.tex` is the standalone vector TikZ source for the dimer-specific
diagrammatic hierarchy. It resolves the matter propagator into the bright/dark
sequences that are implicit in the generic Fan/SCBA topology:

- panel (a): the leading `B -> D -> B` Fan channel retained by both BA and
  SCBA;
- panel (b): the nested noncrossing `B -> D -> B -> D -> B` repetition
  generated by SCBA self-consistency;
- panel (c): the same bright/dark sequence with the lowest crossed phonon
  pairing, which SCBA omits.

The artwork is native vector TikZ. Its black directed propagators, blue dashed
bare-phonon contractions, black vertices, rounded light-gray panel frames, and
neutral black inclusion labels follow the visual vocabulary of the generic SI
Fan/SCBA diagram.  The white under-stroke at the crossing is only a drawing aid
that makes the contraction topology unambiguous.
The coordinate scale gives a native width matched to a `0.75\linewidth` SI
inclusion. Panel titles use 10-pt sans-serif type and the remaining diagram
text stays at 8--9 pt after inclusion.

## Build and output

From the project root, generate the one-page publication PDF with:

```bash
bash Figures/SI/FigS8/build_FigS8.sh
```

The wrapper uses a TikZ-capable `pdflatex` from the current environment (and
also discovers a Windows TeX installation when run under WSL), places TeX
intermediates in `Figures/SI/FigS8/build/`, and writes the final artifact to
`Figures/SI/FigS8/FigS8.pdf`. Successful builds remove the regenerable `.aux`, `.log`,
and intermediate PDF; a failed build retains its log for diagnosis. Set
`PDFLATEX` to select a different engine explicitly.

The immediately preceding TikZ source and PDF are preserved under
`Figures/archive/revision27/FigS10_diagram/`.

## Scientific scope

The figure identifies retained and omitted contraction topologies. The leading
bright--dark conversion is already present in BA and SCBA, so the tuned error
cannot be attributed to omission of that leading channel. The nested
noncrossing rainbow is generated by SCBA self-consistency, whereas crossed and
vertex structures lie beyond this closure. The available ED/Wasserstein
comparison does not isolate any one crossed graph as the unique source of the
discrepancy; the sketch only identifies retained and omitted topologies.
