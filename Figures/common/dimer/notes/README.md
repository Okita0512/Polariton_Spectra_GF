# Dimer theory notes

`single_mode_dimer_scba_theory.tex` and its compiled PDF document the local
Franck--Condon error, exact parity selection rule, and finite-J
commensurability analysis used by the merged SI Fig. S6.

The note predates the merge and uses the archived pre-merge figures
`old_S6_FigS7.pdf` and `old_S7_FigS8.pdf` for its internal comparison. The
manuscript uses only the merged `Figures/SI/FigS6/FigS6.pdf`; both historical
figures are under `Figures/archive/revision28/old_S6_S7/`.
